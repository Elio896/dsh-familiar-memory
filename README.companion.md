# dsh-familiar-memory · 记性

给 AI 伴侣用的本地记忆层。她记得你说过的小事和那天的情绪，**想不起来就说想不起来，不编造共同经历**。
数据是电脑上的一个 `.db` 文件，不联网，你能打开、能改、能删。

DeepSeek Harness 插件 · MIT · 零依赖（Node ≥22.5 内置 SQLite）

## 她会做的事

> 三天前你说「被领导骂了，想吃火锅」。
> 今天你说「想吃点好的」，她问：**补上那顿火锅？**

- **记小事，不记百科**：一句话 + 时间 + 情绪；感受和约定排在档案前面
- **记得住「那天」**：想起一件事，顺手带出同一天前后各一条
- **忘得起，也翻得出**：淡了沉底但不删，你精确问起还能捞回来
- **记不清就承认**：没提到的事不会亮。宁可安静，也不编

## 记错了能改

```sql
UPDATE nodes SET text = '她喜欢猫，不是过敏才不养' WHERE id = 42;
```

一行 SQL，下一轮她就改口。这是它和向量记忆最本质的区别：**你能看见它记了什么，也能改掉。**
（手机 App 里会是「这条别再提了」按钮，0.4.0）

## 三十秒测它有没有用

拿三句话试，不用看文档：

1. 说一件小事 → 隔一天问「你还记得吗」
2. **问一件根本没发生的事** → 她应该回「你没跟我说过」，而不是顺着你演
3. 改一条错记忆 → 看她下一句有没有改口

第 2 条是它存在的唯一理由。过了这条，它才算“记得你”，而不是“会接话”。

## 它不做什么

- **不做语义检索**：只认字面，同义不同字会漏。代价是笨，收益是它不会把「像」当成「是」
- **不会自动冒出来**：DSH 没有消息入站钩子，得接自动注入才有存在感（0.3.0 做主动开口）
- **不做图记忆**：我们试过「神经元网络 + 激活扩散」，实测 1 跳让噪音率 33% → 64%、增量精确率 0%，已从主路径移除。方法和数字都在 [FINDINGS.md](FINDINGS.md)
- **不联网、不上云、不做常驻监听**

## 装

要求：Node ≥ 22.5（内置 `node:sqlite`）、DSH ≥ 0.1.7

```bash
git clone https://github.com/<you>/dsh-familiar-memory
cd dsh-familiar-memory
node install.mjs          # 复制进 profile、登记 bundle、跑自检
dsh plugin add link:$(pwd)
node test-all.mjs         # 四层测试
```

重启一次 DSH，工具和设置页面板就出现。首次运行自动建空库。
想接已有记忆库，在 profile 的 `cordis.patch.yml` 里配：

```yaml
- id: dsh-familiar-memory
  name: dsh-familiar-memory
  config:
    db: /path/to/familiar.db
    source_db: /path/to/memory.db   # 可选：原文库（一张 memories(id,text) 表即可）
```

## 数据在哪

```
$DSH_HOME/familiar-memory/familiar.db
```

- **备份** = 复制这个文件
- **删一条** = `DELETE FROM nodes WHERE id = ?`
- **看它记了什么** = 任何 SQLite 工具打开

## 适合 / 不适合

✅ 陪伴、角色扮演、长期个人助理——需要「记得你」，而且你不想把它放云上
❌ 文档问答、需要引用出处、团队共享知识库——那些该用 RAG，不是它

## 已知问题

- 默认 `hops=0`，所以 `replay` / `prune` 是空操作（这是有意的，见 FINDINGS）
- `config.json` 里的 `hops` / `halfLifeDays` 等参数**不生效**，要写在 `cordis.patch.yml`
- `POST /mode` 空 body 会静默切到闲聊（0.2.0 修）

## 它现在到底在跑什么

坦白说：**bm25 种子 + 情绪桶 + 同日窗口 + 指数衰减**。没有向量，也没有图。

附一份小规模评测（18 题，作者自拟，只能看方向）：

| 方案 | 命中 | 噪音率 | 每千字符命中 |
|---|---|---|---|
| 本插件 | 100% | 33% | 2.93 |
| 扁平 bm25（同 2-gram + IDF） | 94% | 26% | 3.10 |
| 纯权重（不检索） | 22% | 96% | 0.91 |

那 6 个点**没有一个来自图**——唯一差距是空查询时走了兜底。所以图退场了。
方法、归因和复现方式在 [FINDINGS.md](FINDINGS.md)。
